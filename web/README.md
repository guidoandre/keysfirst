# Keysfirst web app

The Next.js app behind https://www.keysfirst.io. What Keysfirst does, the 5-minute demo and the environment variables are in the [root README](../README.md).

## Commands

```bash
npm install
npm run dev        # http://localhost:3000 (needs .env.local, see .env.example)
npm test           # vitest unit tests
npm run lint
npm run build
npm run sync-idl   # copy the IDL and types from `anchor build` (target/) into src/idl
npm run create-test-eur -- https://your-app.example   # one-off: create the Test EUR mint and faucet wallet on devnet
```

## Where things are

| Path | What it holds |
|---|---|
| `src/app/(site)/` | Marketing and legal pages. No wallet code, so they stay fast on phones; links into app routes use `prefetch={false}` |
| `src/app/(app)/` | Wallet pages under one Privy provider: My deals, create a deal (`/new`), deal page, handover, `/start` guide. `/dev/*` are component galleries that 404 in production |
| `src/app/api/` | `gas` (SOL top-up), `checkout/quote`, `pay`, `fulfil`, `pending` (Stripe test card payments), `handover/[id]` (Solana Pay for Phantom), `calendar/[id]` (.ics), `cron/return-deposits` (daily return of expired deposits) |
| `src/lib/` | Deal rules (`rules.ts`, mirrors the program), deal page logic (`deal-view.ts`), pricing, formatting, program client (`program.ts`, `instructions.ts`, `send.ts`) |
| `src/lib/server/` | Server-only code: faucet (mint authority), Stripe client, keeper, rate limits |
| `src/content/` | Copy and data shared by pages: fees, FAQ, countries and their legal deposit caps |
| `src/components/` | UI kit (`ui/`), deal page (`deal/`), marketing sections, site chrome, wallet and card payment |
| `src/idl/` | Generated by `anchor build`, copied with `npm run sync-idl`; don't edit by hand |

## Rules the code keeps

- Deals are read only through `fetchDeal()` / `isGenuineDeal()` in `src/lib/program.ts`, which check the owner program, the deal's own address and the Test EUR mint.
- The deal page never offers an action that `availableActions()` in `src/lib/rules.ts` doesn't return.
- Secrets (`FAUCET_SECRET_KEY`, `STRIPE_SECRET_KEY`, `CRON_SECRET`) are read only under `src/lib/server/` and `src/app/api/`; only `NEXT_PUBLIC_*` values reach the browser. Stripe keys must be test keys; live keys are refused.
